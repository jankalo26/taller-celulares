# Taller de Celulares

Aplicación web para registrar y controlar órdenes de reparación de celulares.

## Cómo instalarla

Antes de empezar, necesitas tener instalados **Node.js** (https://nodejs.org) y **Git** (https://git-scm.com).

1. Descarga el proyecto:
   ```
   git clone https://github.com/jankalo26/taller-celulares.git
   ```
2. Entra a la carpeta del proyecto:
   ```
   cd taller-celulares
   ```
3. Instala lo necesario:
   ```
   npm install
   ```
4. Inicia la aplicación:
   ```
   npm start
   ```
5. Abre en tu navegador: http://localhost:4200
